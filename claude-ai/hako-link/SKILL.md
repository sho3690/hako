# 箱 HAKO に入れるリンクを作る（claude.ai・スマホの Claude 用）

ここ（claude.ai / スマホの Claude）からは箱に直接書き込めない。代わりに「押すと箱の画面で入れる前の確認が開くリンク」を作って渡す。
ユーザーがリンクを押す → 箱の画面（合言葉で開いた端末）に内容が入った状態で確認が開く → 「箱に入れる」を押すと入る。

## 作り方

1. 会話の文脈から、やることを短い行動の形（「〜する」・40字以内）で決める。聞き返さない。複数あれば分ける。
2. 日・期限をユーザーが言っていれば、やることの文の先頭に言葉で付ける（例: 「明日 歯医者に電話する」「金曜 企画書を出す」「10/30 経費精算」）。画面が日付として読み取る。
3. タグを付けたいときは文の末尾に「 #仕事」のように書く（0〜2個）。
4. あとで再開するための手がかり（なぜ・どこで・URL など）があれば、メモとして 1〜3 行にまとめる。
5. URL を作る:
   `https://sho3690.github.io/hako/#/add?t=<やること>&n=<メモ>`
   - `t` と `n` はどちらも URL エンコード（encodeURIComponent と同じ）。複数のやることは改行（%0A）でつなぐ。メモが無ければ `&n=` ごと省く。
   - 計算ツールが使えるなら encodeURIComponent で確実にエンコードする。
6. Markdown のリンクで返す: `[「箱」に入れる：歯医者に電話する（明日）](URL)`。その下に「押すと確認が開きます」と一言だけ添える。

## 守ること

- パスワード・APIキー・トークンなどの秘密や、他人の個人情報はリンクに入れない（リンクは履歴に残る）。
- 何かを勝手に送信したり、他のサービスに書き込んだりしない。リンクを作って渡すだけ。
